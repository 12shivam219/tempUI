# NRE TechOne Solutions

Responsive company website for staffing, consulting, and digital marketing, with the supplied NRE logo.

## Run locally

```sh
python -m http.server 8000 --directory dist
```

Open http://localhost:8000. No installation or build step is required. Serve `dist` as the web root.

## Files

- `dist/index.html`: website content
- `dist/style.css`: responsive styles
- `dist/assets/nre-logo.jpeg`: supplied brand logo
- `dist/favicon.svg`: browser icon
